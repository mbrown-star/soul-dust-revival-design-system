# Cover blends

Thirty-eight cover grounds with the hero photo duotoned in the ground color and blended onto its mottle. Each pairs with the same-numbered file in `cover-mottles`.

- `01`–`15`: the original sunset-family set. Full resolution (~1900px) in this repo.
- `16`–`27`: darker ground-level variations.
- `28`–`38`: production colors from shipped covers.

All names are unique. See `CoverBlendMottlePairings` for every name, its hex value and the recipe. `16`–`38` are 480px wide with no larger source; if print resolution is ever needed, regenerate them from the recipe at full size.
