# Cover blends

Forty-three cover grounds with the hero photo duotoned in the ground color and blended onto its mottle. Each pairs with the same-numbered file in `cover-mottles`.

- `01`–`15`: the original sunset-family set. Full-resolution originals (~1900px) are in the GitHub repo.
- `16`–`27`: darker ground-level variations.
- `28`–`38`: production colors from shipped covers.
- `39`–`43`: production colors from covers shipped after the first set (Gunmetal, Coal, Sapphire, Ochre, Verdigris), added 2026-11-17.

All names are unique. See `CoverBlendMottlePairings` for every name, its hex value and the recipe. The files here are 480px wide. `16`–`43` have no larger source; if print resolution is ever needed, regenerate them from the recipe at full size.
