# Brand marks

Three marks from `LogoVariations` (lockups A, C and D), in the real Anton face:

- `wordmark-stacked`: the primary mark. Two-line wordmark with an ember→gold gradient on ink, a gold rule and "Psalm 119:25". Use it wherever a full lockup fits.
- `monogram-wordmark-lockup`: the SDR badge beside a two-line wordmark, for nav bars, footers and tight horizontal spaces.
- `monogram-badge`: the SDR badge alone, for favicons, avatars and small sizes. Transparent outside the circle.

**Formats:** `.svg` has its text converted to outlines, so it needs no fonts and is safe for print at any size. `.png` is 2x and `@4x.png` is 4x, both with transparent corners.

Colors: ink `#1a120c`, gold `#f6c453`, wordmark gradient `#f6c453` → `#e2762c` → `#b8501f`, scripture line parchment `#f7ecd8` in Source Serif 4 italic.
