# Cover fonts

Bundled so the pipeline renders identically anywhere, including a Claude Chat sandbox:
- `LiberationSerif-*.ttf`: front and back panels (SIL Open Font License, see `LICENSE-Liberation.txt`).
- `DejaVuSerifCondensed*.ttf`: spine (Bitstream Vera license, see `LICENSE-DejaVu.txt`).

`render.py` installs them into `~/.fonts` automatically if the system doesn't already have them.
