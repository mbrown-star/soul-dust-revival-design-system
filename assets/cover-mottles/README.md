# Cover mottles

Forty-three mottled color grounds (flat color + cloud blotch + grain/vignette), the base layer of every cover. Each pairs with the same-numbered file in `cover-blends`.

- `01`–`15`: the original set from `CoverMottleLibrary`. Full-resolution originals are in the GitHub repo.
- `16`–`27`: darker ground-level variations.
- `28`–`38`: production colors from shipped covers.
- `39`–`43`: production colors from covers shipped after the first set (Gunmetal, Coal, Sapphire, Ochre, Verdigris), added 2026-11-17.

All names are unique. See `CoverBlendMottlePairings` for every name, its hex value and the recipe. The files here are 480px wide.
