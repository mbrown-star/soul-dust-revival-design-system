# Cover mottles

Thirty-eight mottled color grounds (flat color + cloud blotch + grain/vignette), the base layer of every cover. Each pairs with the same-numbered file in `cover-blends`.

- `01`–`15`: the original set from `CoverMottleLibrary`. Full resolution in this repo.
- `16`–`27`: darker ground-level variations.
- `28`–`38`: production colors from shipped covers.

All names are unique. See `CoverBlendMottlePairings` for every name, its hex value and the recipe. `16`–`38` are 480px wide.
