Free-form hex color picker (native swatch + text field), used for callout-block background color — the brand deliberately allows any custom color per callout rather than a fixed preset list, defaulting to amber `#fef3c7`.

```jsx
<ColorPicker value={calloutColor} onChange={setCalloutColor} />
```

Pair with a contrast reminder in your own copy — source warns editors to check 4.5:1 body-text contrast before publishing.
